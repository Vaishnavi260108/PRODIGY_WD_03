# PRODIGY_WD_03 – Tic-Tac-Toe Web Application

## 📄 Description
This project is a **Tic-Tac-Toe Web Application** developed as **Task-03** for the **Prodigy Infotech Web Development Internship**.  
It allows two players to play the classic tic-tac-toe game by taking turns and aims to get three markers in a row to win.

## 🚀 Features
- Two-player gameplay (X and O)
- Real-time win and draw detection
- Interactive UI with hover effects
- Reset game functionality

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ▶️ How to Run the Project
1. Clone or download the repository  
2. Open `index.html` in any modern web browser  
3. Click on the grid to play the game  

## 🎯 Task Objective
To build an interactive tic-tac-toe web application using HTML, CSS, and JavaScript by handling user input, tracking game state, and checking winning conditions.
